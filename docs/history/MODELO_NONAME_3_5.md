# Modelo No Name 3.5

## Roles propios

Dirección Deportiva define roles propios por posición. Ejemplo:

```text
MCD · Base
```

Cada rol tiene una descripción de su función dentro del equipo.

## Criterios

Cada rol puede tener criterios técnicos, tácticos, físicos o mentales y peso 1–5. El Scout puede puntuarlos en una observación específica.

El encaje ponderado se calcula solo con criterios realmente valorados.

## Necesidades

Por temporada cada rol puede marcarse como necesidad Alta, Media o cubierta/no prioritaria, con contexto de DD.

## Plantilla sombra

Los jugadores ojeados de la liga pueden asignarse a un rol concreto con:

- estado de temporada;
- prioridad;
- encaje;
- conclusión.

## Histórico

La decisión es estacional. No se sobrescribe el criterio deportivo de años anteriores.

## Planificación

La pestaña `Planificación` busca futuros partidos de los equipos de candidatos vinculados a necesidades abiertas. DD puede convertir una oportunidad en una misión Scout con un clic.
